ArtViSiON - Display Counter (concept v1, 01-Oct-2026)
======================================================

display-counter.html   Open in Chrome / Edge. Three tabs:
                         Counter 3D   - orbit the counter, click a bay (or press 1-5), night / exploded / dimensions / human scale
                         Screen UI    - the touch-screen catalog in a device frame (portrait / landscape, English / Hindi)
                         Build sheet  - sizes, materials, parts list, bay schedule, assembly, electrical, kiosk set-up, assumptions
                       Adapts to laptop, tablet and phone windows (phone: portrait works best). Checked in emulated window sizes only, not on real devices.
kiosk.html             The catalog itself, full-screen, for the counter's 32" portrait touch display.
                       Chrome kiosk mode:  chrome.exe --kiosk --app=file:///C:/kiosk/kiosk.html
                       Keys: 1-5 = bays A-E (wire the five counter buttons to these), L = language, H = home, Esc = back.
drawings/
  ArtViSiON_Counter_Drawing_A3.pdf          A3, 2 sheets: front / section A-A / plan at 1:15, then BOM + notes
  ArtViSiON_Counter_Sheet1_Drawing_A3.svg   same drawing as SVG (open in CorelDRAW)
  ArtViSiON_Counter_Sheet2_BOM_A3.svg       bill of materials sheet as SVG
  ArtViSiON_Counter_BOQ.xlsx                BOQ with blank rate cells, bay schedule, ACP take-off, assumptions

Size: 2400 W x 650 D x 1000 H mm, tower to 2000 mm. Bays A-E = 440 / 440 / 520 / 440 / 440 mm.
Everything is an assumption until confirmed: see "Assumptions to confirm" in the Build sheet.
